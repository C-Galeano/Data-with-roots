Types of Machine Learning

There are three main approaches, each suited to different kinds of problems.

Supervised Learning

The model learns from a dataset that already contains the correct answers (labeled data). It compares its own predictions to the real answers and adjusts itself to reduce errors.

Main Characteristics
  • Requires labeled data (input + known output).
  • The model is guided by the correct answers during training.
  • Performance can be measured against real results.
Problems It Can Solve
  • Regression: predicting a numeric value (e.g. house prices).
  • Classification: predicting a category (e.g. spam or not spam).
Unsupervised Learning

The model works with data that has no labels or correct answers. It tries to find hidden structures, patterns, or groupings on its own.

Main Characteristics
  • Uses unlabeled data (no known outcome).
  • The model discovers patterns without external guidance.
  • Results are often exploratory rather than exact.
Problems It Can Solve
  • Clustering: grouping similar customers together.
  • Dimensionality reduction: simplifying complex data.
Reinforcement Learning

The model (called an "agent") learns by interacting with an environment. It receives rewards for good actions and penalties for bad ones, and gradually learns the strategy that maximizes its total reward.

Main Characteristics
  • Learns through trial and error, not fixed examples.
  • Uses a system of rewards and penalties.
  • The agent improves its strategy over many attempts.
Problems It Can Solve
  • Training agents to play games (e.g. chess, video games).
  • Robotics and autonomous navigation.
