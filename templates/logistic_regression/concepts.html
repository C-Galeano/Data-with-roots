Logistic Regression: Concepts

01 · Fundamentals

What is Logistic Regression?

Logistic Regression is a supervised Machine Learning algorithm used to predict which of two possible categories an observation belongs to, based on one or more independent variables.

Instead of predicting a numerical quantity, it estimates the probability that an observation belongs to a given class, and then uses that probability to assign a final label.

Main Idea

Estimate the probability that an observation belongs to a class, and use that probability to classify it.

02 · Classification

Why is Logistic Regression a Classification Algorithm?

Even though it is built on a linear combination of variables, Logistic Regression does not output a continuous number as its final answer. It transforms that linear combination into a probability between 0 and 1, and that probability is then converted into a discrete class label. That final step, assigning a label instead of a quantity, is what makes it a classification algorithm.

What is Binary Classification?

Binary classification is a type of problem where every observation belongs to exactly one of two possible classes, for example Yes / No or Germinated / Not Germinated. Logistic Regression is the classic algorithm used to solve this kind of problem.

Probability of Belonging to a Class

For every observation, the model calculates a value between 0 and 1 that represents how likely it is that the observation belongs to the positive class (labeled as 1). A probability of 0.90 means the model is very confident the observation belongs to class 1.

X
Independent Variable

The input used by the model to estimate the probability of belonging to a class.

03 · Variables

Independent and Target Variables

As in other supervised models, Logistic Regression uses one or more independent variables (X) to explain or predict a target (dependent) variable (Y).

The key difference is that in Logistic Regression the target variable is not numerical: it is a binary categorical variable, meaning it can only take one of two possible values, usually encoded as 0 and 1.

04 · Classes and Labels

Classes or Labels

The two possible values of the target variable are called classes or labels. Each class must be clearly defined so the model's output can be interpreted correctly. For example:

0

No / Low Risk / Negative class

1

Yes / High Risk / Positive class

05 · Decision Rule

Classification Threshold

Since the model outputs a probability rather than a class, a threshold is needed to turn that probability into a final decision. The most common threshold is 0.5.

Probability < 0.5

The observation is classified as class 0.

Probability ≥ 0.5

The observation is classified as class 1.

06 · Comparison

Linear Regression vs. Logistic Regression

Aspect Linear Regression Logistic Regression
Type of problem Regression (predicts a number) Classification (predicts a class)
Target variable Continuous / numerical Binary / categorical (0 or 1)
Output A number on the real line A probability between 0 and 1
Function used Straight line (Y = β₀ + β₁X) Sigmoid / logistic function
Result interpretation Estimated quantity Probability converted into a class using a threshold

Key Idea

Logistic Regression learns the relationship between one or more independent variables and a binary outcome, expresses that relationship as a probability, and applies a threshold to decide which of the two possible classes each observation belongs to.
