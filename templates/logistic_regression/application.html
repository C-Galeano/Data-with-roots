Logistic Regression

Seed Germination Prediction

Application of Binary Logistic Regression to classify whether a seed will germinate according to soil moisture.

1. Problem Context

Soil moisture is one of the main factors that determines whether a planted seed successfully germinates. Too little moisture prevents the seed from activating its germination process, while adequate moisture levels significantly increase the chance of a seedling emerging.

In this application, the phenomenon being analyzed is the relationship between soil moisture percentage and whether a seed germinates or not. Each record represents one planted seed observed under a given moisture condition.

The purpose of applying Binary Logistic Regression is to estimate the probability that a seed will germinate given a soil moisture level, and to classify each new observation into one of two possible classes: Germinated or Not Germinated.

2. Variables

Independent Variable (X)

Soil_Moisture_Percent

Percentage of moisture present in the soil where the seed was planted.

Unit: percentage (0% – 100%)

Target Variable (Y)

Germinated (binary)

Indicates whether the seed germinated.

0 Not Germinated

1 Germinated

3. Dataset

Dataset: Seed Germination Dataset

Records: {{ total_records }} data records

Source: Synthetically generated for this application, based on a realistic logistic relationship between soil moisture and germination (see data/generate_seed_germination_dataset.py).

Independent variable:
Soil_Moisture_Percent

Target variable:
Germinated (0 = Not Germinated, 1 = Germinated)

Classes:
Two possible classes, as described above.

The dataset is loaded from a CSV file using Pandas and contains one independent variable and one binary target variable, as required for a Binary Logistic Regression model.

4. Train/Test Split and Model Training

Before training, the dataset is split into a training set and a testing set using scikit-learn's train_test_split(), so that the model's performance can later be evaluated on data it has never seen.

80%

Training data

20%

Testing data

The model is implemented in Python using the scikit-learn LogisticRegression class, trained only on the training split.

Process:

CSV Dataset → Pandas → X and y → 80/20 Split → LogisticRegression().fit() → model.predict() → Evaluation → New Classifications
