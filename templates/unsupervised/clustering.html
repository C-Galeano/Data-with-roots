K-Means Clustering Application

Finding natural soil and climate profiles in 2,200 real crop records with Scikit-learn.

01 · Dataset

Dataset and Variable Selection

This section uses the Crop Recommendation Dataset, which records the soil and climate conditions under which 22 different crops grow well. It continues the irrigation theme of the manual exercise: the manual part looked at moisture and germination in a nursery, and this part looks at the broader set of soil and climate conditions across many crops.

The manual exercise used only 2 variables because every distance had to be calculated by hand. Here, with Scikit-learn doing the arithmetic, all {{ dataset.n_features }} numerical variables are used together, which lets K-Means find groups that a 2-variable view would miss.

The crop label itself is not used to train the model — K-Means only sees the 7 numeric columns. The label is kept aside and used afterwards only to help interpret what each cluster represents.

02 · Preprocessing

Preprocessing Steps

1. Data quality check

{{ dataset.n_before }} records loaded. {{ dataset.n_nulls }} missing values and {{ dataset.n_dupes }} duplicate rows were found, so no rows had to be dropped. {{ dataset.n_after }} records remained.

2. Standardization

Unlike the manual exercise, these 7 variables are on very different scales (potassium up to 205, pH only 3.5–10). StandardScaler was applied so every variable contributes equally to the distance calculation.

3. Choosing k

The elbow method was run for k = 2 to 9. The curve bends clearly at k = {{ model.k }}: adding more clusters after that keeps lowering WCSS only a little.

03 · Model

K-Means Configuration

KMeans(
    n_clusters={{ model.k }},
    init="{{ model.init }}",
    n_init={{ model.n_init }},
    random_state={{ model.random_state }}
)
  • n_clusters = {{ model.k }}: chosen with the elbow method above.
  • init = "{{ model.init }}": places the initial centroids far apart from each other instead of purely at random, which gives a better and more stable starting point than the plain random initialization used conceptually in the manual exercise.
  • n_init = {{ model.n_init }}: the algorithm runs {{ model.n_init }} times with different centroid seeds and keeps the run with the lowest WCSS, reducing the risk of a poor local minimum.
  • random_state = {{ model.random_state }}: fixes the randomness so the result is reproducible.

06 · Evaluation

Silhouette Score

{{ silhouette_score }}

A score around {{ silhouette_score }} (on a −1 to 1 scale) indicates a moderate clustering structure: the clusters are real and better than a random split, but they overlap at the edges rather than being perfectly separated. This matches the PCA scatter plot above, where cluster 4 is clearly apart but clusters 1–3 blend into each other. That overlap makes agronomic sense: many crops share similar soil and climate tolerances, so the boundary between "moderate rainfall" and "high rainfall" crops, for example, is naturally fuzzy rather than sharp.

Conclusion

Without ever seeing the crop names, K-Means grouped the records into 4 profiles that line up with recognizable agricultural categories: dryland legumes, humid rainfall-dependent crops, high-nitrogen fruit crops, and a distinct cool-climate, high-P/K orchard group. This mirrors the manual exercise at a larger scale: there, moisture and germination alone revealed 3 irrigation profiles; here, 7 soil and climate variables together reveal 4 broader farming-condition profiles across 22 different crops.
