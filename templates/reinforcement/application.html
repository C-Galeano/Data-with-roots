Q-Learning: Find the Exit

A virtual robot learns to cross a maze by trial and error, using SGDRegressor to estimate the value of each move.

State: the robot's position (row, column), starting at S {{ start }}.

Actions: {{ actions|join(", ") }}.

Rewards: −1 per move, −5 for hitting a wall (#) or the border, +20 for reaching G {{ goal }}.

Model: a one-hot vector of 64 features (16 positions × 4 actions). With no intercept and no penalty, each weight of SGDRegressor is one Q(s, a) value.

2. Training

The agent plays 1000 episodes with an epsilon-greedy policy (epsilon starts at 1.0 and decays to 0.05), γ = 0.95 and a learning rate of 0.1. After every move it builds the target reward + γ · max Q(s′, a′) and updates the model with partial_fit().
