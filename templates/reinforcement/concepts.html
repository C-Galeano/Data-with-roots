Reinforcement Learning

Reinforcement Learning: Concepts

Reinforcement Learning is a machine learning approach in which an agent learns to make decisions by interacting with an environment, receiving rewards or penalties and improving its behavior over time.

Our Q-Learning exercise

In our application, an agent starts at A and must learn how to reach the target T on a 10 × 10 grid. The environment contains normal cells, walls and danger cells. The agent learns through repeated interaction with the environment using Q-Learning.

Reinforcement Learning Concepts

Reinforcement Learning (RL) is a machine learning approach in which an agent learns through interaction with an environment. In our exercise, the agent learns how to move from A to T while maximizing its accumulated reward.

The agent is the learner that makes decisions. In our exercise, the agent is the robot that decides whether to move Up, Down, Left or Right.

The environment is the world in which the agent acts. Here, the environment is our 10 × 10 grid containing the start, target, normal cells, walls and danger cells.

A state represents the current situation of the agent. In our grid, a state is represented by the current row and column of the agent.

An action is a decision made by the agent. The four possible actions in our environment are Up, Down, Left and Right.

A reward is a numerical value returned by the environment after an action. Positive rewards encourage useful behavior, while negative rewards discourage undesirable behavior.

A penalty is a negative reward used to discourage an action or situation. In our environment, moving into danger or attempting an invalid movement produces a negative value.

A policy is the strategy used by the agent to select an action for a given state. After training, the learned policy selects the action with the highest estimated Q-value.

A step is one interaction between the agent and the environment. For example, moving one cell to the right is one step.

An episode is a complete sequence of interactions that starts at A and ends when the agent reaches T or when the maximum number of steps is reached.

An experience is the information obtained from an interaction: current state, action, reward and next state. These transitions are used by the Q-Learning agent to improve its estimates.

Exploration means trying different actions to discover how the environment behaves. In our implementation, exploration is controlled by epsilon.

Exploitation means selecting the action currently estimated as the best. In our implementation, the agent selects the action with the highest Q-value.

Epsilon-Greedy balances exploration and exploitation. At the beginning of training, epsilon is 1.0, so exploration is frequent. It decreases until the minimum value of 0.05.

The immediate reward is the reward received directly after an action. For example, reaching the target produces +100, while entering a danger cell produces -15.

The return represents the accumulated rewards obtained from a sequence of actions. The agent tries to learn actions that lead to a higher future return.

Gamma (γ) is the discount factor that determines how much future rewards influence the current Q-value. Our implementation uses γ = 0.95.

V(s) represents the expected value of being in a particular state under a policy. In our exercise, the important idea is that some states are more valuable because they can lead to the target with better future rewards.

Q(s,a) represents the expected value of taking action a in state s. Our application calculates Q-values for Up, Down, Left and Right.

Q-Learning is the algorithm used in our application to learn the value of actions without being given the correct route. The model updates its Q-value using the received reward and the estimated future value.

Reward System

The environment assigns different rewards depending on what happens after an action.

Situation Reward Effect on the agent
Normal movement -1 Encourages reaching the target efficiently.
Invalid movement / outside grid -3 Discourages leaving the environment.
Wall -5 Discourages attempting to cross walls.
Danger -15 Strongly discourages dangerous cells.
Goal +100 Strongly encourages reaching T.

Q-Learning Parameters

Parameter Value Purpose
Training episodes 300 Number of training episodes.
Gamma (γ) 0.95 Discount factor for future rewards.
Initial epsilon 1.0 Initial exploration level.
Minimum epsilon 0.05 Minimum exploration level.
Epsilon decay 0.98 Reduces exploration after each episode.
Learning rate 0.1 Controls the size of each model update.

Q-Learning Learning Cycle

1. Current State

The agent observes its current position.

2. Select Action

Epsilon-Greedy chooses exploration or exploitation.

3. Environment

The environment executes the action and returns the next state.

4. Reward

The agent receives a reward or penalty.

5. Update Q-value

Q(s,a) is updated using the reward and the estimated future value.

6. Next State

The new state becomes the current state for the next decision.

7. Goal or End

The episode ends when T is reached or the maximum number of steps is reached.

Cycle: State → Action → Environment → Reward → Q-value Update → Next State → Action → ...

Q-Learning Update

The implementation updates the value of the selected state-action pair using the received reward and the estimated future value:

Q(s,a) ← Q(s,a) + α [r + γ max Q(s',a') − Q(s,a)]

In our implementation, the model uses SGDRegressor and partial_fit() to incrementally update the learned Q-values.

How our agent learns

The agent starts without knowing the best route. Through 300 training episodes, it explores the grid, receives rewards and penalties, updates its Q-values and gradually improves its policy. During final evaluation, exploration is disabled and the learned policy is used to select the best action at each state.
