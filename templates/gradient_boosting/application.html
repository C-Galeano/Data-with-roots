Gradient Boosting Classifier

Crop Disease Risk Classification

Application of a Gradient Boosting Classifier to classify the risk of disease outbreak in a crop field based on environmental and soil conditions.

1. Problem Context

Plant diseases, especially fungal ones, spread more easily under certain environmental conditions: warm temperatures, high humidity, and heavy rainfall create a favorable environment for pathogens, while healthy, nutrient-rich soil helps plants resist infection.

In this application, the phenomenon being analyzed is the relationship between temperature, humidity, rainfall, and soil nitrogen level recorded for a crop field on a given day, and whether that field is at high or low risk of a disease outbreak. Each record represents one observation of a field under a set of environmental conditions.

The purpose of applying a Gradient Boosting Classifier is to learn the (often non-linear) combination of these four conditions that leads to higher disease risk, and to classify each new observation into one of two possible classes: Low Risk or High Risk.

2. Variables

Independent Variables (X)

  • Temperature_C · average field temperature, in Celsius.
  • Humidity_Percent · average relative humidity, in percentage.
  • Rainfall_mm · accumulated weekly rainfall, in millimeters.
  • Soil_Nitrogen_Level · soil nitrogen index, from 0 (poor) to 100 (healthy).

Target Variable (Y)

Disease_Risk (binary)

Indicates whether the field is at risk of a disease outbreak.

0 Low Risk

1 High Risk

3. Dataset

Dataset: Crop Disease Risk Dataset

Records: {{ total_records }} data records

Source: Synthetically generated for this application, based on a realistic weighted relationship between environmental conditions and disease risk (see data/generate_crop_disease_dataset.py).

Independent variables:
Temperature_C, Humidity_Percent, Rainfall_mm, Soil_Nitrogen_Level

Target variable:
Disease_Risk (0 = Low Risk, 1 = High Risk)

Classes:
Two possible classes, as described above.

The dataset is loaded from a CSV file using Pandas and contains four independent variables and one binary target variable, meeting the requirement of using three or more independent variables for the assigned classification model.

4. Train/Test Split and Model Training

Before training, the dataset is split into a training set and a testing set using scikit-learn's train_test_split(), so that the model's performance can later be evaluated on data it has never seen.

80%

Training data

20%

Testing data

The model is implemented in Python using the scikit-learn GradientBoostingClassifier class, trained on all four independent variables using only the training split.

Process:

CSV Dataset → Pandas → X (4 variables) and y → 80/20 Split → GradientBoostingClassifier().fit() → model.predict() → Evaluation → New Classifications
