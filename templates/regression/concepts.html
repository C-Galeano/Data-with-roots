Linear Regression: Concepts

01 · Fundamentals

What is Linear Regression?

Linear Regression is a supervised Machine Learning algorithm used to model and analyze the relationship between two or more quantitative variables.

Its main purpose is to find a linear relationship between variables and use that relationship to estimate or predict numerical values.

In its simplest form, Linear Regression uses one independent variable to predict the value of one dependent variable.

Main Idea

Find the best straight line that represents the relationship between two quantitative variables.

02 · Applications

What Problems Can Linear Regression Solve?

Linear Regression is useful when the objective is to understand relationships between numerical variables or predict a numerical value.

Predict Values

Estimate a numerical value based on information from one or more independent variables.

Identify Trends

Identify whether an increase or decrease in one variable is associated with changes in another variable.

Analyze Relationships

Measure and describe the relationship between quantitative variables using a mathematical model.

X
Independent Variable

03 · Variables

Independent Variable

The independent variable is the variable that is used as an input in the model. It is commonly represented by the letter X.

In Linear Regression, changes in the independent variable are used to help explain or predict changes in the dependent variable.

04 · Variables

Dependent Variable

The dependent variable is the value that the model attempts to explain or predict. It is commonly represented by the letter Y.

Its value may change depending on the independent variable. In a prediction problem, this is the numerical value we want the model to estimate.

Y
Dependent Variable

The numerical value that the model tries to predict.
