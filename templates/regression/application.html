Linear Regression

Estimate Number of Customers

Application of Simple Linear Regression to estimate the number of customers according to daily marketing spend.

1. Problem Context

Coffee shops invest money in marketing campaigns and promotions with the objective of attracting more customers. However, it is important to understand whether there is a relationship between the amount of money invested in marketing and the number of customers received per day.

In this application, the phenomenon being analyzed is the relationship between daily marketing spend and the number of customers per day. The data represents daily observations from a coffee shop environment.

The purpose of applying Simple Linear Regression is to identify the relationship between these two quantitative variables and use that relationship to estimate the number of customers expected for a given daily marketing investment.

2. Variables

Independent Variable (X)

Marketing_Spend_Per_Day

Daily amount of money invested in marketing campaigns and promotions.

Unit: US dollars per day ($/day)

Dependent Variable (Y)

Number_of_Customers_Per_Day

Total number of customers visiting the coffee shop during a day.

Unit: customers per day

3. Dataset

Dataset: Coffee Shop Daily Revenue Prediction Dataset

Records: {{ total_records }} data records

Source: Kaggle

Marketing_Spend_Per_Day

Unit: US dollars per day ($/day)

Number_of_Customers_Per_Day

The dataset contains more than the required 500 records for the implementation of the Simple Linear Regression model.

4. Linear Regression Model

The model is implemented in Python using the scikit-learn library. The independent variable is used as the input and the dependent variable represents the value that the model attempts to predict.

Training process:

Dataset → Pandas → X and Y → LinearRegression() → model.fit() → model.predict()
